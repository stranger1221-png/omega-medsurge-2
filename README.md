# Omega Medsurge — Interactive Modern Experience (Option 02)

Official website for **Omega Medsurge**, medical equipment and healthcare technology supplier based in Hyderabad, Telangana, India.

## Key Features

- **Hero Experience**: Real medical equipment photography integrated with an abstract Three.js orbital gyroscope.
- **Interactive Solutions Explorer**: Horizontal multi-department category explorer with active indicators and instant preview switching.
- **Endless 3D Concave Carousel**: Custom 3D curved cylinder equipment gallery with drag, snap, and mobile touch fallback.
- **Connected Healthcare (Astral Shell)**: Constellation network visual metaphor.
- **Tactile Typography**: Elastic lettering, luminous statement spotlight reveal, and signal type illuminated signage.
- **Performance & Tech Stack**:
  - Next.js 14 (App Router)
  - React 18, TypeScript, Tailwind CSS
  - Three.js & @react-three/fiber
  - GSAP & ScrollTrigger with Lenis smooth scrolling integration
  - Motion (`motion/react`)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
